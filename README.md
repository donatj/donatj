### What I've been up to recently

I’ve been extending [MDDoc](https://github.com/donatj/mddoc), my PHP-to-Markdown documentation generator, with smarter configuration discovery. It now recognizes common `.dist.xml` configuration names in a clear preference order, which should make it easier to share sensible project defaults without extra setup.

I’ve also made generated API documentation easier to navigate in [MDDoc](https://github.com/donatj/mddoc): recursive documentation can now opt into a linked table of contents for classes, interfaces, and methods. I’m aiming to make large generated reference pages practical to browse rather than just complete; the work is captured in [adding a navigable table of contents for recursive API docs](https://github.com/donatj/mddoc/pull/56).

Over in [AlikeColorFinder](https://github.com/donatj/AlikeColorFinder), I’ve been smoothing out the programmatic color-extraction API by letting callers omit diagnostic output when they do not need it. That keeps the CSS color-consistency tool simpler to embed while preserving detailed errors for callers that want them; I’ve got this in [making extraction-error output optional](https://github.com/donatj/AlikeColorFinder/pull/38).
